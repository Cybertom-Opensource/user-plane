# User Plane
Welcome to the CyberTom User Plane repository! This service is responsible for managing user authentication, subscriptions, and authorization. It interacts with the Control Plane to issue keys for clients connecting to the VPN network.

## About
The User Plane is a critical component of the CyberTom VPN system. Its primary responsibilities include:
- Handling user login and session management.
- Managing user subscriptions and entitlements.
- Authenticating users and issuing necessary credentials for accessing VPN services.
- Communicating with the Control Plane to provision client keys.

## Features
- Secure user authentication mechanisms.
- Subscription management with support for different tiers.
- Integration with the Control Plane for key distribution.
- API endpoints for managing user sessions and subscriptions.
